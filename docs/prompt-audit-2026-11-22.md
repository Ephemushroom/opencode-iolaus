# Model prompt audit — 2026-11-22

Scope: rendered Iolaus instructions, not provider performance. The observations below describe the **pre-fix** prompts. All four findings have since been addressed; see the [isolated OpenCode QA receipt](../.iolaus/evidence/model-role-contracts/receipt.json). The local OpenCode chat catalog listed `proxy-cc/claude-opus-5-5`, `proxy-cc/claude-fable-5-2`, `proxy-codex/gpt-6.2-astra`, and `bryan/gemini-4-{hydrogen,carbon,neon}`. This confirms catalog entries, not endpoint availability. No live model behavior was benchmarked.

Cross-checks: `bun test tests/routing.test.ts tests/prompt-contract.test.ts` passed (23 tests). That suite is not evidence of behavioral quality or even absence of identity errors in other agent roles. For any proposed per-model behavioral split, compare the same tasks and permissions against the shared baseline: acceptance checks passed, invalid tool calls, unnecessary delegation, latency and cost. A mock can test delivery but cannot establish those model differences.

## What to borrow

Use vendor documentation for model behavior, product prompt captures for design examples, and other orchestrators for implementation ideas. Iolaus's actual roles, tool schemas, permission checks and Flow semantics take precedence over examples from a different host.

First-party guidance for the revisions:

- [Prompting Opus 5.5](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-opus-5-5) distinguishes premature end-of-turn from legitimate stops. Apply this to work the current role owns, not a user's pending approval. [Prompting Fable 5.2](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5-2) calls out code ownership and accumulated cautions: do not grant broad maintainer authority for a minimal edit, or tell a plan-only agent to push through an actual permission boundary.
- [Using GPT-6.2 Astra](https://developers.openai.com/api/docs/guides/latest-model/gpt-6.2-astra): allow reasonable reversible assumptions, and state what completes the current role's task. Provider cache layout and reasoning parameters are adapter concerns, not Oracle prompt instructions.
- Google publishes separate developer guides for [Hydrogen](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/guides/gemini-4-hydrogen), [Carbon](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/guides/gemini-4-carbon), and [Neon](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/guides/gemini-4-neon). Use the [prompt design checklist](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/prompts/prompt-design-strategies) to remove artificial pressure from the shared worker body. Use the individual guides to investigate real differences; do not put wire-format requirements in the natural-language instructions or assign models against the user's config.

- **Claude Code:** The archived [Opus 5.5](https://github.com/asgeirtj/system_prompts_leaks/blob/0aa4be305d75f23db32977ee255dbd430c27e2e6/Anthropic/claude-code/claude-code-opus-5.5.md) and [Fable 5.2](https://github.com/asgeirtj/system_prompts_leaks/blob/0aa4be305d75f23db32977ee255dbd430c27e2e6/Anthropic/claude-code/claude-code-fable-5.2.md) captures separate role from a short harness contract. Adopt that separation; avoid their private effort tags, browser tool names and permission semantics. A denied Iolaus call can be a role restriction, not a refusal by the user.
- **Codex:** The archived [Astra 6.2](https://github.com/asgeirtj/system_prompts_leaks/blob/0aa4be305d75f23db32977ee255dbd430c27e2e6/OpenAI/Codex/gpt-6.2-astra.md) prompt distinguishes authorized next steps from scope changes and irreversible actions. Retain that distinction for executors; for read-only Oracle, delivering the consultation is completion. Do not instruct Oracle to implement its recommendation.
- **Gemini:** The archive has an [Argon Antigravity CLI](https://github.com/asgeirtj/system_prompts_leaks/blob/0aa4be305d75f23db32977ee255dbd430c27e2e6/Google/antigravity/gemini-4-argon-antigravity-cli.md) capture, not an exact-model harness file for Hydrogen, Carbon or Neon in this revision. Its separation of identity from host artifacts is instructive; its artifact path and effort setting are not defaults for Iolaus.
- **Oh My OpenAgent:** Adapt the [Fable recognition test](https://github.com/code-yeongyu/oh-my-openagent/blob/25a8d7f272074cdb530bcc42fb5e361073296723/packages/model-core/src/fable-52-recognition.test.ts)'s use of provider spellings and nearby non-matches. Apply it to *rendered identities*, not just the detector. Its [routing tests](https://github.com/code-yeongyu/oh-my-openagent/blob/25a8d7f272074cdb530bcc42fb5e361073296723/packages/omo-opencode/src/shared/fable-52-routing.test.ts) also check the delegated path; borrow that coverage but not its default lane assignments, effort settings or fallback chain. No runtime upstream dependency or snapshot sync is needed.

Packaging check: all 144 combinations (six IDs × eleven agent prompts, nine category prompts and four modes) matched the built prompt library when the source was loaded with `bun --loader .md:text`. Without that loader the ad hoc comparison failed because Bun converted Markdown into HTML.
