# DAG popup interaction verification

Base: dev 59f3e7a. Host and SDK: OpenCode 2.0.18.

## Regression

The previous sidebar registered bare-letter actions outside a focused view.
Against the unchanged main checkout, typing `jkoar` into the composer failed
the new live assertion: `DAG shortcuts swallowed text intended for the composer`.
The baseline trace also recorded an unintended approval. The negative case is
retained in `20260927-popup-red/failure.txt` and its trace.

The sidebar is now an overview. Clicking a run or node opens a native dialog;
the node click selects that exact node. A launcher in the app slot also opens
the dialog through the command palette or `<leader>d`, including when a narrow
terminal hides the sidebar. Only the focused dialog has single-letter actions.

## Live checks

Both commands passed with isolated HOME/XDG directories, dedicated tmux servers,
local mock models and the built plugin:

```sh
node script/qa-tui.mjs .omo/evidence/20260927-popup-final-verified
IOLAUS_QA_THEME=dark node script/qa-tui.mjs .omo/evidence/20260927-popup-final-verified-dark
```

The harness verifies:

- A new waiting gate does not open a dialog.
- Typing `jkoar` in the composer neither loses characters nor executes actions.
- Keyboard entry opens the dialog at the waiting gate.
- `Esc` restores the draft and cursor: after moving left twice in `jkoar`,
  opening/closing the popup and typing `X`, the composer contains `jkoXar`.
- Clicking a gate opens its details without opening an agent session.
- `k` selects the preceding judge; `j` returns to the gate; `a` approves it.
- The open dialog updates as the run completes.
- Enter opens the successor agent session and closes the popup, without
  submitting the draft or creating another DAG.
- Closed-dialog key bindings no longer intercept composer input.
- Resizing from 160 to 100 columns stacks the node and detail panes.
- Keyboard entry works while the host hides the sidebar.
- The command palette discovers and opens the same dialog, preserving the draft.
- Light/dark foreground colors and live theme changes remain correct.

Receipts assert unchanged hashes of the real host configuration/database and
removal of the QA sandboxes. Selected ANSI captures are included; full local
terminal logs and intermediate attempts are not part of the change.

The existing two-location live RPC regression also passed in
`20260927-popup-routing`: explicit location routing finds the correct run,
approving project B does not change A, and unrelated owners remain hidden.
